# Contexto del proyecto para Claude Code

**No hay una arquitectura específica de Claude.** Este archivo es únicamente una puerta de entrada para un asistente de desarrollo.

Lee y sigue [`AGENTS.md`](AGENTS.md) y [`PROJECT_CONTEXT.md`](PROJECT_CONTEXT.md); el índice canónico de diseño y progreso es [`docs/context/README.md`](docs/context/README.md). Antes de modificar componentes, revisa las decisiones, las pruebas del código y el roadmap pertinentes. No asumas que la CLI de Claude será el backend de inferencia del agente final. Si los archivos se contradicen, informa de la discrepancia en lugar de inventar una solución.
